# Clean-room rules for this repository

This app is a clean-room implementation. Its only permitted input about the
desired behavior is the approved specification in `~/Projects/epub-reader-spec`
(features.md, performance.md, corpus.md, tools/).

Anyone (human or agent) working in this repository must NOT:
- open, read, list or search `~/Projects/epub-reader-dirty`, or any other
  material derived from observing another reader app;
- install, run, decompile or look up the code, resources or screenshots of
  any existing commercial/proprietary EPUB reader for reference;
- copy UI text, icons, layouts or visual design from another reader app.

Open-source libraries may be used under their licenses. Questions about the
spec go to the gatekeeper in writing and are recorded in
`~/Projects/epub-reader-spec/HANDOFF_LOG.md`.
